# Knock design spec

## Subject
A career concierge that opens doors for MBA grads and PM switchers in India. The brand name and tagline are about a door, so the page is built around one: a lacquered peacock-green door with a brass knocker.

## Tokens
- Peacock `#0F4A45` is the door colour and the dark sections
- Peacock deep `#0A3632` is the footer and form backdrop
- Lime-wash `#E9EEE8` is the page background, a cool painted-wall tone (not cream)
- Ink `#15201E` is the text colour
- Sage `#56635F` is secondary text (5.6:1 on lime-wash)
- Brass `#DDB36C` is used on dark, dark brass `#7A5418` on light, and the button fill is brass

## Type
- Gloock (high-contrast display serif) is used only for headlines and the big statements
- Onest (humanist grotesk) is used for body, UI and the form
- Scale is based on 1.25: 15/17 body, 21, 27, 34, 54, 84 display

## Layout
```
[Knock]                         [Get my target list]
Stop applying.            |  ______
Start conversations.      | / door \   <- knocker taps, door opens a crack
subline + CTA             | |  o   |
--------------------------------------------------
(dark) grid of 24 closed small doors, one open  | Portals are a queue. People hire people.
--------------------------------------------------
How it works: sticky heading | 1 2 3 4 steps on a hallway line + approval note
Why it works: one large statement + three plain points
Example message: the message on a plain surface with margin notes
Packages: 3 columns, Standard raised; one shared "all include" line; done-for-you row
FAQ: disclosure list
(dark) Intake form
Footer
```
Text is left-aligned throughout. Nothing is centred except the button labels.

## Principles
- The door is the one bold element and everything else stays quiet
- Motion happens once: two knocks, then the door opens a crack. Nothing else animates on its own
- Numbers appear only for the four real steps
- No eyebrows, no all caps, no arrows in buttons, no middle-dot meta strings

## Review against generic defaults
- The first idea was a warm cream page with a serif display. I switched to a cool lime-wash wall colour, peacock and brass, which come from painted Indian doors and brass knockers
- Packages as identical cards with shadows was swapped for columns separated by rules. Only Standard gets a filled ground, so its fill carries meaning
- A 3-up "why it works" icon grid was swapped for one oversized statement plus a plain list
