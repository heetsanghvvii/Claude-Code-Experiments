# Hook Bank

Status: PLACEHOLDER. Agents pick from and adapt these. Never copy a hook verbatim twice (check /memory/post-log.md).

## How to log a hook
Format: `- [HOOK TEXT] | type | platform | result (views/saves/etc.) | date`

## Hook types
- Contrarian: challenges a common belief
- Specific result: number + timeframe + outcome
- Curiosity gap: withholds the payoff
- Story: opens mid-scene
- List/promise: "N things that..."
- Callout: names the exact reader
- Mistake: "I did X wrong for Y years"
