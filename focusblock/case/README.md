# Nope puck: case files

The current design lives in `../product/case/` (v1.0 "pebble"). This folder is kept so older links still work.

File: `nope_puck_60mm.stl`
- Now an exact copy of `product/case/nope_body.stl` (v1.0). The name is historical: the puck is 64 mm, not 60 mm.
- 64 mm round, 16 mm tall, wide pillow roll on the top edge (10 x 7.5 mm), flat matte top with "nope" debossed 0.8 mm.
- Hidden 25 mm NTAG213 sticker under a 2.4 mm top skin, closed by a quarter-turn bayonet base cap (`product/case/nope_base_cap.stl`) or, as a fallback, a 58 mm self-adhesive felt pad.
- Print top up, PETG, see `product/README.md` for the full order sheet.

v0.2 (60 x 12 mm, 5 mm top radius) was rejected because it did not match the brand photo and has been overwritten.

Everything is generated by `product/case/build_case.py`. Edit parameters there, never this STL by hand.
